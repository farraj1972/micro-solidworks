## Objective and bounded scope

Deliver **N2 for one class of personally fabricated prismatic adapter plates**, not for the whole CAD product. The complete job is New Part → planar Sketch with rectangular outer loop **and circular inner loop** → driving dimensions/constraints → general additive Extrude (forming the axial through-hole) → Sketch on Face → one axial Cut Extrude (forming the blind pocket) → edit/rebuild → Undo/Redo → native Save/Close/Open → validated STL export → independent slicer inspection at the intended scale → prepare the print, using a Windows package without developer tools. Physical printing can strengthen evidence but is not required for N2.

Authorized for *planning*: STL export, independent mesh quality validation, Windows Release/portable distribution, repeatable mechanical reference workflow, product Experience Gate and user guidance. Existing Sketch, Extrude, Cut, Feature Manager, Undo/Redo and persistence v2 are preserved. Explicitly excluded: Revolve, Fillet, Chamfer, Hole Wizard, assemblies, general Boolean, persistent topology naming, STEP/DXF import/export, kernel replacement, CAM toolpaths and installer complexity not needed for a portable release.

## Proposed synthetic reference fixture

These are **fixed candidate acceptance dimensions, not a real user part**: plate 80 × 50 × 8 mm, one Ø8 mm through-hole at local (-22, 0) mm, one 18 × 14 mm rectangular blind pocket centered at (+16, 0) mm with 2 mm depth. Base XY sketch coordinates: outer X `[-40,40]`, Y `[-25,25]`, Z=0; circle centre `(-22,0)`, radius 4. Extrude +Z to Z=8. EndCap sketch uses local +X/+Y axes at Z=8; pocket corners `(7,-7)` and `(25,7)`; reverse Cut -Z leaves floor Z=6. The **base sketch's inner circle creates the through-hole during additive Extrude**; the sole Cut Extrude creates the separated pocket. Drive at least plate width/height/thickness, hole diameter and pocket depth; for example edit width 80 → 90 mm about the fixed origin and pocket depth 2 → 3 mm, then rebuild, Undo/Redo and Save/Open. Expected finished initial volume is `31,093.8761403405` mm³ and AABB X `[-40,40]`, Y `[-25,25]`, Z `[0,8]`; after both edits, volume `34,841.8761403405` mm³ and AABB X `[-45,45]`, Y `[-25,25]`, Z `[0,8]`. R2 independently measured matching exact CAD shell volumes within `10⁻⁶` mm³ and matching AABBs, and validated the complete edit/history/persistence chain in permanent automated tests. The owner subsequently validated the CAD Experience Gate; this does not establish export mesh quality or the complete N2 workflow. Change fixture dimensions only through owner review, preserving reproducibility. A second fixture should exercise a round pocket/curved mesh boundary; multi-body export needs its own contract fixture, whether accepted or rejected with a clear diagnostic.

## STL and mesh contract questions for C1

Authoritative source: [`FeatureModel`](../src/features/FeatureModel.h) derived `topology::Solid` results, never OpenGL meshes or GPU buffers. Tessellation must be a reproducible derivation, with explicit linear/angular or chord tolerance and bounded triangle count. Validate planar faces with inner wires, circular edges and cylindrical side faces, shared seam vertices and caps. Define whether one STL contains all selected nonoverlapping bodies or one file per body; a disconnected-but-watertight file may be valid, but overlapping bodies need an explicit rejection or merge policy. Clarify active/result feature versus visible scene and do not accidentally export hidden historical bodies.

Candidate first contract: binary STL for compact output, explicit **millimetres** in the UI/guide and metadata outside STL if needed; never assert that STL itself encodes units. Use consistent outward winding and computed normals, finite coordinates, nondegenerate triangles, edge incidence two per manifold closed component, no inconsistent seam/winding and positive signed volume. Compare analytic CAD bounding box and expected fixture volume against exported mesh within an agreed tolerance; this catches scale and missing-face faults but does not prove manufacturability. A robust independent parser must check the written file and the external slicer must report the intended 80 × 50 × 8 mm extent for the initial fixture. Surface continuity/self-intersection checks should cover the reference plate and cuts; a general self-intersection engine may be deferred if unsupported shapes are rejected with a diagnostic. Roundtrip means re-reading the STL as a **mesh for verification**, not restoring parametric history.

Error cases should include invalid/empty result, failed or blocked feature, nonfinite coordinates, excessive tessellation, open/nonmanifold/degenerate mesh, ambiguous multi-body selection and file I/O failure. No silently partial STL; write transactionally where practical. Decide numeric thresholds empirically from fixtures in C1, not by copying viewport display settings.

## Windows distribution and lifecycle

Prefer a portable package if clean-machine evidence supports it. Inventory the Visual C++ runtime and any shipped DLLs/assets, verify Windows 10 compatibility, Release build and CMake install/packaging feasibility, start/Save/Open/Export/close from an unpacked directory, and place user documents/settings/logs in appropriate user locations. Capture actionable failure diagnostics without exposing private document content by default. Define package version, `.microsw` v1/v2 read compatibility, future upgrade path, and safe handling of failed Save/Export. A complex installer, updater or telemetry system is outside this first proposal.

## Acceptance and evidence plan

**Technical Gate:** reference CAD topology/volume/bounds; edit/rebuild determinism; Undo/Redo; persistence roundtrip; STL manifold/winding/normals/nondegeneracy/size/scale, repeatability, independent parse; targeted regression then meaningful full integration gate; Release package launch and file operations on clean Windows 10. Failure diagnostics must preserve native document integrity.

**Experience Gate:** a mechanically CAD-literate owner can discover the complete sequence and complete it without internal IDs, understand cut/edit/export state and recover from an invalid input; user guide follows the same commands; save/export paths are clear.

**N2 Gate:** independently open the exported STL in a slicer, confirm 80 × 50 × 8 mm initial extent (or formally revised fixture), orientation and intended hole/pocket, and prepare a print from the supported Windows package without SolidWorks. Record receiver name/version and result. A physical print is optional evidence. A valid CAD Solid, valid tessellation, watertight mesh, slicer acceptance and real-world printability are distinct findings; report each separately. N2 attaches only to this fixture/workflow, never to the whole product.

## Risks, decisions and future work

High risks: export seams outside the bounded fixtures, unitless STL scale and incomplete runtime packaging. The [V1.2-PLAN-R1 preflight](PERSONAL_SOLIDWORKS_V1_2_GEOMETRY_PREFLIGHT.md) reproduced `Incident Faces must traverse a shared Edge oppositely` when making the one blind pocket on a through-holed base. R2 repaired the CAD orientation issue; [C1](PERSONAL_SOLIDWORKS_V1_2_C1_VALIDATION.md) subsequently validated a bounded derived mesh for that fixture. This is not general manufacturability evidence. **Current [`FeatureModel::rebuild`](../src/features/FeatureModel.cpp) also rejects a Cut Extrude whose target is another Cut Extrude** (it requires an Extrude target); this remains outside the first-N2 sequence. If preserving accepted CAD/Presentation/Rendering separation is impossible, stop and seek a narrow owner-approved gate; no silent renderer-to-CAD inversion.

The final K1/K2/K3 kernel choice remains **OPEN — EVIDENCE REQUIRED**. A future isolated OCCT spike, independent of first N2, should compare supported primitives, oblique Boolean, Revolve, Fillet/Chamfer, STEP, face correspondence, `FeatureModel` integration, v1/v2 document reconstruction, license and Windows distribution. Success requires reproducible build, correct fixture geometry/topology, stable edit/rebuild mapping and acceptable license/package cost; reject on failed invariants, migration incompatibility without a viable path or unmanageable distribution. No spike is executed here. DXF, STEP, drawings, assemblies, suppression/reorder, topological naming and CAM remain later hypotheses, not approved releases.
