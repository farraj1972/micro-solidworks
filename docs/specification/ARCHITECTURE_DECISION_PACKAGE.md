# Future Architecture Decision Package — PROPOSED, NOT ACCEPTED

The [source specification §10](sources/MICRO_CADCAM_PRODUCT_SPEC_V0_1.md) suggests several gates. This package identifies *decision questions*, not approved ADRs or a required gate for every implementation detail. [P0-D07](../PERSONAL_SOLIDWORKS_P0_DECISIONS.md) permits a gate only when a material architectural choice is actually required. Accepted ADR-0001–0069 and [`DEPENDENCY_POLICY.md`](../DEPENDENCY_POLICY.md) remain binding. First test whether v1.2 STL export/portable Windows distribution fit existing CAD-authoritative/derived-mesh and Application boundaries; a narrow gate is needed only for a concrete unresolved conflict.
