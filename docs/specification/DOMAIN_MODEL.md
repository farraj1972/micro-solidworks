# Domain Model — Existing versus Conceptual

Source: [specification v0.1 §2](sources/MICRO_CADCAM_PRODUCT_SPEC_V0_1.md). **Conceptual target, DRAFT:** `Project → Document → Part | Assembly | Drawing | ManufacturingPlan`. This diagram is not an implemented class hierarchy or a proposal to move current ownership without a Decision Gate.

| Conceptual aggregate and relationships | Existing concrete mapping at v1.1.0 | Gap or ownership/identity question |
|---|---|---|
| Project / Document | [`PersistenceSession`](../../src/app/PersistenceSession.h) owns file/session state; [`FeatureModel`](../../src/features/FeatureModel.h) is the authoritative CAD aggregate. | No Project aggregate or general typed Document. A future wrapper must avoid duplicating FeatureModel authority and preserve `.microsw` v1/v2 migration. |
| Part → Sketches, Bodies, Datums, Parameters, FeatureGraph | FeatureModel owns Sketch/Extrude/Cut/Boolean records, stable `FeatureId`, ordered dependencies and derived `SolidFeatureCache`. [`Sketch`](../../src/core/sketch/Sketch.h) owns local entities/constraints; [`Solid`](../../src/core/topology/Solid.h) models B-rep-like topology. | No general Part aggregate, datum registry, named expression table or general persistent generated-face mapping. Bodies/topology are derived from features, not parallel authoritative Part state. |
| Assembly → ComponentInstances / Mates | No assembly modules or persisted instance/mate aggregate found. | Needs part-reference identity, placement, mates and separate document ownership before implementation. |
| Drawing → Views / dimensions / tolerances | Viewer renders the 3D model; no drawing document found. | Projected views, annotation semantics and CAD revision references need future contracts. |
| ManufacturingPlan → CADReference, Setups, Stock/Fixtures, Tools, Operations, Toolpaths, Simulation, NCArtifacts | No CAM module or NC artifact writer found. | Proposed plan must reference an immutable CAD revision or fingerprint; updates make derived CAM outputs `STALE`. Decide whether CAM is a separate aggregate/document, never a renderer cache. |

Existing identity is intentionally scoped: `FeatureId` persists inside FeatureModel; sketch entity IDs are sketch-local; visual and topology IDs are derived/transient. [`SemanticFaceSupport`](../../src/features/FeatureModel.h) supports restricted generated cap roles for Sketch-on-Face, not universal topological naming (ADR-0064 and ADR-0069). A future general naming service, assembly component identity, drawing references or CAM revision link may affect ADR-0041–0048 and ADR-0064–0069, requiring owner approval before changes. Current CAD representation stays authoritative; [`SolidDisplay`](../../src/presentation/SolidDisplay.h) and OpenGL buffers stay derived.
