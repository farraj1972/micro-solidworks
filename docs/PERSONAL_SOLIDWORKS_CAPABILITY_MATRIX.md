# Personal SolidWorks — v1.1.0 Capability Matrix

Status: P0 REVIEW READY (2026-10-19). Evidence is the frozen `v1.1.0` source at `774f55c`; this is an inventory, not approval to implement. `IMPLEMENTED` means the stated bounded contract exists, not parity with a commercial CAD system. `PARTIALLY IMPLEMENTED` means a usable subset exists; `FOUNDATIONAL ONLY` means supporting types or infrastructure exist without a complete user workflow; `NOT IMPLEMENTED` means no delivered capability was found. Test-file references establish automated coverage, not a fresh test run.

| Capability / state | Module and contract; usable behavior | Limit and evolution risk | Test evidence; direct dependencies |
|---|---|---|---|

| Parametric rebuild — IMPLEMENTED | [`FeatureModel::rebuild`](../src/features/FeatureModel.h): ordered dirty closure, failure/blocked diagnostics and last-good cache. | Complex topology correspondence is limited; no generalized stable generated-face naming. | [`feature tests`](../tests/features/test_feature_model.cpp); features -> modeling/constraints. |
| Persistence — IMPLEMENTED | [`Persistence`](../src/persistence/Persistence.h): JSON `.microsw` v2 writer, v1 reader, bounds, temporary file/replace, transactional load/rebuild. | Proprietary project format; no interchange or recovery journal; cache/topology IDs are regenerated. | [`persistence tests`](../tests/persistence/test_persistence.cpp); persistence -> features. |
| Rendering/tessellation — PARTIALLY IMPLEMENTED | [`SolidDisplay`](../src/presentation/SolidDisplay.h), [`rendering`](../src/rendering): derived shaded triangles/edges and OpenGL 3.3 display. | Bespoke tessellation needs independent manifold/watertight export validation; mesh is not authoritative CAD. | [`solid display tests`](../tests/presentation/test_solid_display.cpp), [`render tests`](../tests/rendering); presentation -> topology, rendering -> presentation. |

| Distribution — NOT IMPLEMENTED | No installer/portable release pipeline found in [`CMakeLists`](../CMakeLists.txt). | Runtime DLL collection, upgrades, crash logs and compatibility policy needed for non-developer use. | No distribution gate; application/build boundary. |

## Workflow gap matrix

Priority and complexity are proposals, not measured effort. **P0/P1** denote critical path for the proposed first printed-part N2; **P2/P3** are later. “Required” depends on the selected workflow.

| Capability | Current state | Required for workflow | Gap | Complexity | Priority |
|---|---|---|---|---|---|
| Sketch editing | PARTIALLY IMPLEMENTED | Printed prismatic part | Limited tool/repair vocabulary | Medium | P1 |
| Constraints | PARTIALLY IMPLEMENTED | Stable dimensions | Solver diagnostics/coverage | High | P1 |
| Extrude | IMPLEMENTED | Plate/body | Advanced end/merge deferred | Medium | P1 |
| Cut | PARTIALLY IMPLEMENTED | Through/blind holes and pockets | Axial subset only | High | P0 |
| Revolve | NOT IMPLEMENTED | Shaft/bushing | No feature/kernel path | High | P2 |
| Hole feature | NOT IMPLEMENTED | Frequent drilled parts | Construct from sketch/cut today | Medium | P2 |
| Fillet / chamfer | NOT IMPLEMENTED | Edges on many real parts | Surface/edge topology operations absent | Very high | P2 |
| Pattern / mirror | NOT IMPLEMENTED | Repeated holes/symmetry | Feature transforms/dependency semantics absent | High | P2 |
| Sweep / loft | NOT IMPLEMENTED | Complex parts | General surface construction absent | Very high | P3 |
| Assemblies | NOT IMPLEMENTED | Multi-part assembly | Part instances, mates and BOM absent | Very high | P3 |
| Technical drawings | NOT IMPLEMENTED | Manufacturing drawings | Views, annotations, tolerances absent | Very high | P2 |
| STL export | NOT IMPLEMENTED | 3D printing handoff | Validated watertight mesh writer needed | Medium | P0 |
| STEP export/import | NOT IMPLEMENTED | Exact CAD exchange | Broad B-rep/schema/identity or external kernel needed | Very high | P2 |
| DXF export/import | NOT IMPLEMENTED | 2D cutting/drawing | Units, arcs, layers and entity mapping needed | Medium–high | P2 |
| Suppression / reorder | NOT IMPLEMENTED | Complex history repair | Frozen history semantics need decision | High | P2 |
| Topological naming | FOUNDATIONAL ONLY | Robust downstream face references | Restricted semantic cap roles only | Very high | P2 |
| Measurement tools | NOT IMPLEMENTED | Fit/check before export | Pick-derived readout absent | Medium | P1 |
| Mass properties | NOT IMPLEMENTED | Material estimation/weight | Volume/centroid/density contract absent | High | P2 |
| Interference detection | NOT IMPLEMENTED | Assemblies | General intersection/collision absent | Very high | P3 |

No row claims a current N2 end-to-end manufacturing workflow. See the [review](PERSONAL_SOLIDWORKS_PRODUCT_ARCHITECTURE_REVIEW.md) and [roadmap proposal](PERSONAL_SOLIDWORKS_ROADMAP_PROPOSAL.md).
