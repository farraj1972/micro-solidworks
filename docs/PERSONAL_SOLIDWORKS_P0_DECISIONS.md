# P0.FREEZE — Personal SolidWorks Product Strategy

Status: **P0 FROZEN** (2026-10-19). Owner approval of the seven P0 decisions is recorded here. This is a product-planning freeze, not an executable baseline or an approval to implement v1.2. Micro SolidWorks `v1.1.0` remains FROZEN at `774f55c` / tag `v1.1.0`; ADR-0001–0069 remain ACCEPTED. The code-based [P0 review](PERSONAL_SOLIDWORKS_PRODUCT_ARCHITECTURE_REVIEW.md) and [matrix](PERSONAL_SOLIDWORKS_CAPABILITY_MATRIX.md) retain their evidence-cut date.

| Decision | Status | Approved contract and boundary |
|---|---|---|
| **P0-D01 — Product positioning** | **APPROVED** | Personal parametric 3D CAD for progressively replacing real individual mechanical-engineering workflows, not full SolidWorks parity. Product over Education; Workflow over Feature; Build or Integrate Pragmatically; Progressive Functional Replacement; CAD Data Integrity First. Keep **Micro SolidWorks** as technical name and repository; **Personal SolidWorks** is the working vision. Do not copy commercial branding, code, UI, icons or assets; consider a distinct product name separately. |
| **P0-D02 — Target workflows** | **APPROVED** | Individual mechanical parts for personal fabrication: initially prismatic plates, simple flanges, supports and adapters with axial holes/pockets. The required chain is Create → Sketch → Constrain/Dimension → Model → Edit → Rebuild → Save/Open → Export → validate manufacturing output. Assemblies and general mechanical modeling are outside this first target. |
| **P0-D03 — Kernel strategy** | **APPROVED WITH EXPLICIT LIMITATION** | Keep the current internal Math, Geometry and Topology for the *first N2 workflow only*. FeatureModel/CAD geometry stay authoritative; tessellation and rendering stay derived. Do not start OCCT migration or integrate CGAL/another kernel. K1 internal, K2 hybrid and K3 external remain future options. The final K1/K2/K3 decision is **OPEN — EVIDENCE REQUIRED**; propose a separate isolated, primarily OCCT spike before approving general B-rep/advanced-surface capabilities. That spike is not a blocker for the first N2. |
| **P0-D04 — Interoperability** | **APPROVED** | Validated STL export is first; DXF for 2D fabrication and STEP for exact CAD exchange are future evaluations. STL is a derived mesh, not parametric CAD or an unambiguous units carrier. Preserve native `.microsw` documents. Define closed/nondegenerate/consistently oriented mesh, normals, scale/units convention, multi-body behavior, tessellation tolerance, repeatability and independent validation. No STEP/DXF/IGES implementation is authorized in the first campaign. |
| **P0-D05 — First N2** | **APPROVED** | A parametric adapter plate for 3D-print preparation, with a circular axial hole and an axial pocket. Exercise sketch/constraints, additive and cut extrusion, face sketch, edit/rebuild, Undo/Redo, Save/Open, STL and independent consumer validation. Use a reproducible synthetic fixture, not invented user-part data. N2 applies only to this bounded workflow when its required steps pass without commercial CAD. |
| **P0-D06 — v1.2 scope** | **APPROVED AT CAMPAIGN LEVEL — IMPLEMENTATION PLAN PENDING** | `v1.2 — First Functional Replacement: Printable Mechanical Part` may be *planned* around STL export, mesh validation, Windows Release/portable distribution, a reference workflow, Experience Gate and user guidance. Preserve existing Sketch/Extrude/Cut/Feature Manager/Undo/Redo/persistence v2. ## Product and acceptance interpretation

The approved strategic priority guide is: Correctness → CAD Data Integrity → Workflow Completeness → Usability → Modularity → Maintainability → Performance → Educational Value. [`AGENTS.md`](../AGENTS.md) still has its own normative project-priority order, including Learning Value ahead of feature completeness and performance. **P0-D01 does not silently amend that hierarchy.** If a concrete implementation trade-off makes them conflict, stop for an owner-approved governance/architecture update; neither order may be used to bypass accepted ADRs or dependency policy.

Autonomy levels are **N0** demonstration, **N1** assisted workflow, **N2** functional replacement for a specified complete job, and **N3** preferred personal workflow. The *full reference fabrication workflow* in v1.1.0 remains **N1**: STL export and supported Windows distribution are absent, despite C5's approved bounded editing Experience Gate. N2 requires modeling, parametric edit/rebuild, native Save/Open, validated watertight STL, independent consumer acceptance with checked scale/orientation/units, usable preparation for printing, and execution from a supported Windows package without a development environment. A physical print is useful supplementary evidence, **not mandatory** for N2. Distinguish a valid CAD Solid, valid tessellation, watertight STL, slicer compatibility and real printability; none alone proves all the others. Never assign N2 to the entire product from one completed fixture.

The [v1.2 campaign proposal](PERSONAL_SOLIDWORKS_V1_2_CAMPAIGN_PROPOSAL.md) is **READY FOR REVIEW / NOT AUTHORIZED FOR IMPLEMENTATION**. K1/K2/K3 is still open. The 69 accepted ADRs, the existing [dependency policy](DEPENDENCY_POLICY.md) and the v1.1.0 release contract are unchanged.
